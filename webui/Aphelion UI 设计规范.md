## 0. 规范性说明

### 0.1 规范性用语

| 用语 | 级别 | 含义 |
|---|---|---|
| **必须**、**不得** | 强制 | 违反即为缺陷，不得发布。只能通过第 17.4 节的例外流程豁免 |
| **应当**、**不应** | 推荐 | 默认遵守；不遵守时要在评审中说明理由 |
| **可以** | 允许 | 由实现者自行决定 |

### 0.2 规则编号

每条规则的编号格式是 `AP-<领域>-<序号>`，例如 `AP-COL-03`。编号一经发布不再改变含义；废弃的规则保留编号并标注「已废弃」。在代码评审、提交说明和例外标注里，一律用编号引用规则。

规则表中「检查」一列的含义：

| 标记 | 含义 |
|---|---|
| 自动 | 由 `tools/aphelion_lint.py` 检查，违反时检查不通过 |
| 自动·警告 | 由检查工具提示，不阻止发布 |
| 评审 | 需要人工按附录 B 检查 |

### 0.3 术语

| 术语 | 含义 |
|---|---|
| 令牌 | 样式库 `:root` 中以 `--ap-` 开头的自定义属性，是颜色、间距、圆角、动效的唯一来源 |
| 面板 | `.ap-board`，一块带外框的承载区域 |
| 格子 | `.ap-tile`，面板中的一个区块 |
| 读数 | 来自硬件的测量值 |
| 派生值 | 浏览器根据读数计算出的值，例如频率、占空比 |
| 实体控件 | 模拟物理操作的控件：实体按键、滑块滑钮 |
| 入口图标 | 顶栏全局入口和工具的图标 |
| 构建产物 | 由 `src/build.py` 生成的 `index.html`、`index.html.gz`、`preview.html` |

## 1. 设计原则

五条原则按优先级排列。规则之间出现冲突、或规范没有覆盖到的情况，按这个顺序判断。

| 编号 | 原则 | 说明 |
|---|---|---|
| P1 | **状态如实** | 页面上的每个数字、每种状态都必须来自设备或明确标注的计算。没有数据就显示「—」，演示数据必须标出。这条原则高于美观 |
| P2 | **读数第一** | 每页有一个最大的数字，其余内容按重要程度逐级变小。用户扫一眼就该知道当前状态 |
| P3 | **一种强调色** | 橙色只标两类东西：能按的实体控件，以及正在变化或被选中的数据 |
| P4 | **用线分区** | 页面像一块硬件前面板：一整块面板，用 1 px 线分区，不用阴影和独立卡片 |
| P5 | **离线自足** | 设备在热点模式下、手机没有互联网时，页面必须完整可用 |

## 2. 颜色

### 2.1 调色板

调色板由**中性色、墨色和一种强调色**组成。完整的值见附录 A。

| 角色 | 令牌 | 浅色值 | 用途 |
|---|---|---|---|
| 机身 | `--ap-bg` | `#E2E2DE` | 页面底色 |
| 面板 | `--ap-panel` | `#F2F2EF` | 所有内容的承载面 |
| 结构线 | `--ap-line` | `#CBCBC5` | 面板外框、格子之间 |
| 未点亮 | `--ap-off` | `#D9D9D3` | 轨道、空段、内容细线 |
| 墨 | `--ap-ink` | `#141414` | 主文字、读数、主按钮 |
| 次墨 | `--ap-ink-2` | `#3D3D39` | 次级正文 |
| 说明 | `--ap-muted` | `#62625C` | 标签、单位、元信息 |
| 禁用 | `--ap-faint` | `#9A9A94` | 仅禁用状态 |
| 强调 | `--ap-accent` | `#FF5000` | 见 AP-COL-03 |
| 焦点 | `--ap-focus` | `#D64300` | 仅焦点环（见 AP-STA-10） |
| 强调文字 | `--ap-accent-ink` | `#B23A00` | 错误、演示标记、危险按钮 |
| 读数 | `--ap-readout` | `#141414` | 读数 XL / L 的数字（深色主题下比墨色略暗，见 V2） |
| 在线 | `--ap-ok` | `#178A3B` | 仅在线状态灯 |

### 2.2 规则

| 编号 | 级别 | 规则 | 检查 |
|---|---|---|---|
| AP-COL-01 | 强制 | 样式、页面和脚本中**不得**出现原始色值（`#RRGGBB`、`rgb()`、`hsl()`），一律使用 `--ap-*` 令牌。只有令牌定义块和独立 SVG 文件的回退值可以写原始色值 | 自动 |
| AP-COL-02 | 强制 | **不得**新增第三种强调色。`--ap-ok` 只用于在线状态灯，不得用于按钮、文字、图表或任何其他元素 | 评审 |
| AP-COL-03 | 强制 | `--ap-accent` 只能用于：实体控件（实体按键、滑钮）、最新或选中的数据点、电平削峰段、工作中状态灯、选中行的强调条、图标和素材中的强调元素。焦点环使用 `--ap-focus`（同色相、加深以满足 3 : 1）。其他用途一律禁止 | 评审 |
| AP-COL-04 | 强制 | `--ap-accent` **不得**用于文字（对比度不足）。需要橙色文字时使用 `--ap-accent-ink` | 评审 |
| AP-COL-05 | 推荐 | 一个视口内强调色的面积**不应**超过 2%。评审方法：在 390 × 844 和 1280 × 800 两种视口下截图，统计强调色像素占比；或者按数量判断，一屏内强调元素**不应**超过 4 处 | 评审 |
| AP-COL-06 | 强制 | **不得**用红、黄、绿表示数值高低或好坏。状态用文字表达，必要时配合状态灯 | 评审 |
| AP-COL-07 | 强制 | 新增颜色时，**必须**先在本规范附录 A 登记令牌，同时给出浅色和深色值，并满足 AP-A11Y-01 | 评审 |

## 3. 主题

深色主题使用**同一组令牌名、另一组值**。组件代码对主题无感知。

| 写法 | 效果 |
|---|---|
| `<html data-theme="dark">` | 强制深色 |
| `<html data-theme="light">` | 强制浅色 |
| 不设置 | 跟随系统外观 |

| 编号 | 级别 | 规则 | 检查 |
|---|---|---|---|
| AP-THM-01 | 强制 | 主题只能通过 `data-theme` 属性和 `prefers-color-scheme` 切换，不得用其他类名或脚本逐个改颜色 | 评审 |
| AP-THM-02 | 强制 | 组件**不得**为某个主题单独写样式（不得出现 `[data-theme=…] .ap-xxx` 这类选择器）。深色下有问题时，补令牌 | 自动 |
| AP-THM-03 | 强制 | 画布在绘制时读取令牌值，并在主题切换后重绘 | 评审 |
| AP-THM-04 | 强制 | 页面**必须**在样式生效前设定 `data-theme`（`<head>` 中的内联脚本），打开时不得先闪一下浅色 | 评审 |
| AP-THM-05 | 强制 | 仿真屏的底色按设备屏幕的光学类型决定，与网页主题无关（见 AP-SCR-03）。128 × 64 OLED 在两种主题下都是黑底 | 评审 |
| AP-THM-06 | 推荐 | 主题设置只保存在浏览器，不同步到设备 | 评审 |

## 4. 文字

### 4.1 字体

只用系统字体，不打包字体文件：

```
--ap-sans: -apple-system, BlinkMacSystemFont, "SF Pro Display", "Segoe UI",
           "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC",
           Roboto, system-ui, sans-serif;
--ap-mono: ui-monospace, "SF Mono", "JetBrains Mono", Menlo, Consolas,
           "PingFang SC", monospace;
```

### 4.2 文字层级

| 级别 | 类名 | 字号 | 字重 | 用途 | 数量限制 |
|---|---|---|---|---|---|
| 读数 XL | `.ap-readout` | 92–184 px | 250（深色 300） | 页面主读数 | 每页 ≤ 1 |
| 读数 L | `.ap-readout--l` | 64–104 px | 300 | 次读数 | 每格 ≤ 1 |
| 读数 M | `.ap-readout--m` | 30–42 px | 400 | 辅助读数、时钟、测量值 | — |
| 标题 2XL | `.ap-title-2xl` | 36–64 px | 700 | 工具详情页名称 | 每页 ≤ 1 |
| 标题 XL | `.ap-title-xl` | 30–48 px | 700 | 页面标题 | 每页 ≤ 1 |
| 标题 L | `.ap-title-l` | 22–28 px | 600 | 状态句、表单标题、空状态 | — |
| 标题 M | `.ap-title-m` | 20–24 px | 650 | 工具卡名称、产品名 | — |
| 标签 | `.ap-label`、`.ap-tag > h*` | 14 px | 600 | 面板名、控件名 | — |
| 正文 | `body` | 16 px | 400 | 说明段落 | — |
| 小字 | `.ap-small` | 14 px | 400 | 反馈、列表内容 | — |
| 说明 | `.ap-caption` | 13 px | 400 | 读数说明、表单提示 | — |
| 元信息 | `.ap-meta` | 12 px 等宽 | 400 | 型号、规格、计数 | — |
| 微字 | `.ap-micro` | 11 px 等宽 | 400 | 刻度、阶段标记 | — |

带区间的字号由 `clamp()` 随视口缩放。行高：正文 1.5，标题 1.05–1.3，读数 0.86–1。

**字重回退**：250、650 这类中间字重只有可变字体（SF Pro、Noto Sans SC 可变版）能精确渲染。PingFang SC 会回退到最接近的 Ultralight / Thin / Semibold，微软雅黑只有 Light、Regular、Bold 三档。读数只有数字，所以 250 在 Windows 上会显示为 Light（300）；650 显示为 Bold（700）。这是可以接受的回退，评审时以 macOS 和 iOS 的效果为准，并在 Windows 上检查一次不发糊、不过粗。

### 4.3 读数排版细节

| 项目 | 规定 |
|---|---|
| 单位 | 字号为读数的 0.28–0.34 倍，与数字**顶部**对齐（`align-items: flex-start`），左边距 `--ap-s1`；本地屏同样规定（`SCREEN.md` AP-DLY-09） |
| 小数点与冒号 | 左右各收紧 0.06 em，避免在大字号下显得空 |
| 缺失值 | 「—」的占位宽度等于两位数字（`min-width: 2ch`），数据回来时布局不跳动 |
| 数字特性 | `font-variant-numeric: tabular-nums slashed-zero`，区分 0 和 O；时钟不用 slashed-zero |
| 负号 | 「−」（U+2212）与数字等宽，紧贴数字，不留空格 |
| 深色主题 | XL、L 读数的颜色用 `--ap-readout`，XL 的字重提到 300。深色背景上细笔画容易发光、发糊（光渗效应） |

### 4.4 规则

| 编号 | 级别 | 规则 | 检查 |
|---|---|---|---|
| AP-TYP-01 | 强制 | 字体**只能**使用 `--ap-sans` 和 `--ap-mono`；不得加载 Web 字体 | 自动 |
| AP-TYP-02 | 强制 | 字号**只能**使用第 4.2 节表中的级别；不得新增字号 | 评审 |
| AP-TYP-03 | 强制 | 所有数字使用等宽数字（`tabular-nums`），每秒刷新时不得左右跳动 | 评审 |
| AP-TYP-04 | 强制 | 等宽字体只用于：元信息与规格、地址与代码、原始字节、时钟、坐标刻度、表格数字列 | 评审 |
| AP-TYP-05 | 强制 | 遵守第 4.2 节的数量限制 | 评审 |
| AP-TYP-06 | 强制 | **不得**使用斜体、全大写标签和装饰性下划线。下划线只用于链接、文字按钮和设备地址 | 评审 |
| AP-TYP-07 | 推荐 | 说明段落的行宽**应当**不超过 60 字（`.ap-measure`） | 评审 |
| AP-TYP-08 | 强制 | 读数遵守第 4.3 节的排版细节：单位顶部对齐、缺失值占位、深色主题用 `--ap-readout`。样式库已实现，页面不得覆盖 | 评审 |

## 5. 间距

| 令牌 | 值 | 典型用途 |
|---|---|---|
| `--ap-s1` | 4 px | 读数与单位 |
| `--ap-s2` | 8 px | 同组小元素、按钮组 |
| `--ap-s3` | 12 px | 说明与读数、列表 |
| `--ap-s4` | 16 px | 设置行上下、面板之间 |
| `--ap-s5` | 20 px | 面板头与首块内容 |
| `--ap-s6` | 24 px | 大块内容之间 |
| `--ap-s7` | 32 px | 面板头与主读数、分组标题上方 |
| `--ap-s8` | 48 px | 页面底部、空状态上下 |
| `--ap-pad` | 18–30 px | 格子内边距 |

页面竖向使用 **4 px 基线网格**：所有间距令牌都是 4 的倍数，`--ap-pad` 由 `clamp()` 计算后取整到 4 的倍数（20、24、28）。

工具类：`.ap-mt-1` … `.ap-mt-8`、`.ap-pt-5` … `.ap-pt-7`、`.ap-push`（推到格子底部）、`.ap-span-all`（在分栏里占满整行）。

| 编号 | 级别 | 规则 | 检查 |
|---|---|---|---|
| AP-SPC-01 | 强制 | 页面布局的间距**只能**使用上表 8 个值。组件内部可以使用 2、3、6 px 做微调，页面布局里不得使用 | 评审 |
| AP-SPC-02 | 强制 | 格子内边距使用 `--ap-pad`，不得自定义 | 评审 |
| AP-SPC-03 | 推荐 | 面板头与首块内容间隔 20 px；面板头与主读数间隔 32 px | 评审 |
| AP-SPC-04 | 推荐 | 同一行格子的面板头基线、主读数基线**应当**对齐；格子高度不同时，内容从顶部开始，操作用 `.ap-push` 贴底，不得垂直居中 | 评审 |

## 6. 形状、线条与层次

| 令牌 | 值 | 用于 |
|---|---|---|
| `--ap-r-seg` | 2 px | 电平段、信号格 |
| `--ap-r-s` | 4 px | 横幅 |
| `--ap-r-ctl` | 10 px | 输入框、列表悬停底、仿真屏、原始数据块 |
| `--ap-r-board` | 18 px（≤ 600 px 时 14 px） | 面板外框 |
| `--ap-r-pill` | 999 px | 按钮、分段、徽标、开关 |

| 编号 | 级别 | 规则 | 检查 |
|---|---|---|---|
| AP-SHP-01 | 强制 | 圆角**只能**使用上表 5 个令牌。面板内部的格子没有圆角 | 评审 |
| AP-SHP-02 | 强制 | 线宽一律 1 px，只有两种线：`--ap-line` 结构线和 `--ap-off` 内容细线。例外仅限：横幅左侧 3 px 强调条、选中行 3 px 强调条、工具图形 2 px 强调线段 | 评审 |
| AP-SHP-03 | 强制 | **不得**使用阴影。唯一例外是实体控件（实体按键、滑钮）的下沿阴影 `--ap-press` | 评审 |
| AP-SHP-04 | 强制 | **不得**使用渐变、毛玻璃、发光、3D 效果和半透明叠层。曲线背景网格和滑块轨道使用的硬边 `linear-gradient` 没有颜色过渡，不属于渐变 | 评审 |
| AP-SHP-05 | 推荐 | 可以使用第 6.1 节的**丝印元素**来强化硬件面板感。每块面板最多一种，每页最多两处；只用 1 px `--ap-line` 或 `--ap-off`，不填充、不用强调色 | 评审 |

### 6.1 丝印元素

模仿仪器前面板上的丝印：只有线和等宽小字，不承载数据，删掉后页面信息不变。

| 元素 | 类名 | 画法 | 用于 |
|---|---|---|---|
| 定位角标 | `.ap-mark--corner` | 面板四角内侧 6 × 6 px 的 L 形，1 px `--ap-line`，距边 `--ap-s2` | 页面标题面板、仿真屏外框 |
| 刻度尺 | `.ap-mark--ruler` | 主读数下方 1 px 底线，每 8 px 一个 3 px 短刻度，每 40 px 一个 6 px 长刻度，`--ap-off` | 主读数格子 |
| 面板序号 | `.ap-mark--index` | 面板头左侧 11 px 等宽 `01`、`02`…，`--ap-muted`，与标题间隔 `--ap-s2` | 实时工具页的第二块面板 |

丝印元素加 `aria-hidden="true"`；减少动态效果和打印时照常显示。

## 7. 动效

| 令牌 | 值 | 用于 |
|---|---|---|
| `--ap-t-fast` | 150 ms | 悬停变色、电平段点亮 |
| `--ap-t` | 200 ms | 分段、开关、图标按钮等状态切换 |
| `--ap-t-fill` | 600 ms | 数值填充（湿度条） |
| `--ap-t-press` | 80 ms | 实体按键按下 |
| `--ap-ease` | `cubic-bezier(.2,.7,.2,1)` | 位移与填充 |

| 编号 | 级别 | 规则 | 检查 |
|---|---|---|---|
| AP-MOT-01 | 强制 | 网页的过渡时长**只能**使用 `--ap-t-*` 令牌。样式库里还定义了本地屏专用的 `--ap-m-*`、`--ap-ease-in`、`--ap-ease-move`（附录 A.2），它们只导出到固件，网页**不得**使用 | 自动 |
| AP-MOT-02 | 强制 | **不得**使用入场动画、数字滚动、加载转圈和装饰性动画。页面打开即为最终状态 | 评审 |

## 9. 布局

### 9.1 页面骨架

```
header.ap-wrap.ap-top
  ├─ .ap-brand            产品名 + 当前构建配置
  ├─ nav.ap-seg           主页面切换
  └─ .ap-actions          全局入口（圆形图标按钮）+ 状态灯
main.ap-wrap.ap-main
  ├─ p.ap-banner          整页问题横幅（需要时）
  └─ section × N          每个页面一个 section，用 hidden 切换
```

### 9.2 面板网格

面板分 12 栏，格子用 `.ap-w3` … `.ap-w12` 指定宽度。网格是弹性分配的：格子被隐藏后，同行剩下的格子自动补满。

| 场景 | 组合 |
|---|---|
| 主读数 + 次读数 | 7 + 5 |
| 带图的数据 + 控制 | 8 + 4 |
| 状态 + 列表或表单 | 5 + 7 |
| 两张同级卡片 | 6 + 6 |
| 三张小卡片 | 4 + 4 + 4 |
| 标题、说明、列表、详情 | 12 |

### 9.3 断点

| 断点 | 变化 |
|---|---|
| ≤ 780 px | 格子全部变为整行（`.ap-m6` 变为半行）；分栏 `.ap-split` 变为单列 |
| ≤ 600 px | 分段导航移到第二行并占满宽度；面板圆角 14 px |
| ≤ 480 px | 测量网格变为两列 |

### 9.4 规则

| 编号 | 级别 | 规则 | 检查 |
|---|---|---|---|
| AP-LAY-01 | 强制 | 页面使用第 9.1 节的骨架。每个 section 有且只有一个 `h1`（可以是视觉隐藏的 `.ap-sr`） | 评审 |
| AP-LAY-02 | 强制 | 内容**必须**放在 `.ap-board` 的 `.ap-tile` 里；同一行格子的宽度之和为 12 | 评审 |
| AP-LAY-03 | 强制 | 断点**只能**是 780、600、480 px | 评审 |
| AP-LAY-04 | 强制 | 宽度 390 px 时页面**不得**横向滚动；宽表格放在 `.ap-table-wrap` 里在自身容器内滚动 | 评审 |
| AP-LAY-05 | 强制 | 分段导航只放主页面，最多 3 项，每项不超过 6 个汉字。全局入口用圆形图标按钮，最多 3 个，放在状态灯左侧 | 评审 |
| AP-LAY-06 | 强制 | 格子内部从上到下依次是：面板头 → 主内容 → 辅助信息 → 操作。操作按钮放在最后，用 `.ap-push` 贴底 | 评审 |
| AP-LAY-07 | 强制 | 每个格子以 `.ap-tag` 面板头开始。页面标题格子和空状态除外 | 评审 |
| AP-LAY-08 | 推荐 | 优先使用第 9.2 节的常用组合 | 评审 |
| AP-LAY-09 | 强制 | 切换页面（分段导航、全局入口、工具详情、「‹ 全部工具」）时同步更新 `location.hash`（例如 `#tools/pwm`）和 `document.title`（「PWM 发生器 · Aphelion」）；浏览器的返回和前进按钮按 hash 切换页面；带 hash 打开时直接进入对应页面 | 评审 |

### 11.4 智能设备管理页

配合 `SCREEN.md` 的表盘、日历、计时、通知和本地屏设置，控制台在遵守 AP-LAY-05（主分段导航最多 3 项，全局入口按钮最多 3 个）的前提下提供管理界面：

| 编号 | 级别 | 规则 |
|---|---|---|
| AP-PAT-20 | 强制 | 「日历与日程」页采用 5 + 7 状态 + 操作页结构：左侧是日历订阅地址、同步状态和「立即同步」按钮；右侧是未来 30 天的只读日程列表。必须区分「没有日程」和「日历未同步」（P1） |

## 12. 数据显示

| 编号 | 级别 | 规则 | 检查 |
|---|---|---|---|
| AP-DAT-01 | 强制 | **不得**显示固件没有返回、也不能由返回值计算出的数值 | 评审 |
| AP-DAT-02 | 强制 | 缺失的值显示「—」（U+2014），不得显示 0、NaN、null 或空白 | 评审 |
| AP-DAT-03 | 强制 | 负号用「−」（U+2212），不用连字符 | 自动 |
| AP-DAT-04 | 强制 | 读数保留 1 位小数；电压保留 2 位；计数不保留小数；派生值按量级自动换单位（Hz/kHz、µs/ms/s） | 评审 |
| AP-DAT-05 | 强制 | 数值和单位之间留一个空格，°C 和 % 也一样。单位写法：`°C`、`%RH`、`dB SPL`、`dBFS`、`dBm`、`Hz`、`kS/s`、`ms`、`µs`、`mV`、`V`、`KiB` | 评审 |
| AP-DAT-06 | 强制 | 演示或合成数据必须挂「演示」徽标（AP-BDG-01） | 评审 |
| AP-DAT-07 | 强制 | 超出量程时显示真实值，图形截断到量程边界，并标出量程 | 评审 |
| AP-DAT-08 | 强制 | 设备没有名称时显示「（无名称）」或「（隐藏网络）」，用 `--ap-muted`，排序时排在有名称的后面 | 评审 |
| AP-DAT-09 | 强制 | 状态轮询每秒一次；波形最多 10 帧/秒，处理不过来时丢弃旧帧，并显示已丢弃的帧数 | 评审 |
| AP-DAT-10 | 强制 | 设备返回的字符串一律用 `textContent` 写入（AP-ENG-06）；SSID 按十六进制传输后在前端解码 | 评审 |
| AP-DAT-11 | 强制 | **数据新鲜度**：距上次成功读取 ≤ 3 秒正常显示；3–30 秒保留旧值，数值改用 `--ap-muted`，并在面板头右侧写「最后更新 hh:mm:ss」；超过 30 秒所有读数变为「—」并显示离线横幅。本地屏 R1 / R2 屏同样适用，R3 墨水屏见 `SCREEN.md` AP-DOP-24 | 评审 |
| AP-DAT-12 | 强制 | **日期、时间与大数格式**：时间一律用 24 小时制（`hh:mm` 或 `hh:mm:ss`）；日期写「M 月 D 日 周X」（如「11 月 23 日 周一」），ISO 8601（`YYYY-MM-DD`）只用于导出和日志；相对时间（「3 分钟前」）只用于通知列表；≥ 10 000 的整数用不换行窄空格（U+202F）千分位分组 | 评审 |
